## Usage

<Callout title="Rows are axes, not points">
  On a line chart each row is a point along the x-axis. On a radar each **row
  is one spoke** of the web, and each series becomes a single closed polygon
  spanning every spoke. So there is no `xDataKey` here: the angle-axis
  categories come from the rows themselves, and `<PolarAngleAxis dataKey>`
  only overrides which column labels them.
</Callout>

```tsx
<EChartsRadarChart data={data} config={config}>
  <EChartsRadarChart.PolarGrid gridType="polygon" />
  <EChartsRadarChart.PolarAngleAxis dataKey="month" />
  <EChartsRadarChart.Tooltip />
  <EChartsRadarChart.Legend />
  <EChartsRadarChart.Radar dataKey="desktop">
    <EChartsRadarChart.Dot variant="border" />
  </EChartsRadarChart.Radar>
</EChartsRadarChart>
```

<ApiHeading>&lt;PolarAngleAxis&gt; and &lt;PolarRadiusAxis&gt;</ApiHeading>

`<PolarAngleAxis>` labels the perimeter; `dataKey` overrides which column is
used. `<PolarRadiusAxis>` takes no props — its presence shows the radial scale.

<ApiHeading>&lt;Dot&gt;, &lt;ActiveDot&gt;, &lt;Tooltip&gt;, &lt;Legend&gt;</ApiHeading>

Dots nest inside a `<Radar>` as they do inside a `<Line>`. The legend defaults
to below the chart, centred.
