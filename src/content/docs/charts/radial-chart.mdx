## Usage

Like the pie chart, `config` is keyed by each bar's **name** — one bar per row.

```tsx
<EChartsRadialChart data={data} config={config} nameKey="browser">
  <EChartsRadialChart.RadialBar dataKey="visitors" showBackground />
  <EChartsRadialChart.Tooltip />
  <EChartsRadialChart.Legend />
</EChartsRadialChart>
```

## Gauges

Without `max`, the scale comes from the data, so the largest bar always fills
the arc. That is right for comparing values and wrong for a gauge, where a
single number has to read against a fixed total. Set `max` for gauges:

```tsx
<EChartsRadialChart data={[{ name: "cpu", load: 72 }]} config={config} nameKey="name" max={100} variant="semi">
  <EChartsRadialChart.RadialBar dataKey="load" showBackground />
</EChartsRadialChart>
```

<ApiTable>
  <ApiRow name="dataKey" type="string" required>Determines each bar's arc length.</ApiRow>

<Callout title="Why the track is a second polar system">
  `showBackground` does not tint the bar's own background. The track is a
  separate series on its own polar coordinate system, drawn beneath — which is
  what lets it keep a constant thickness while the bars animate their sweep.
</Callout>

<ApiHeading>&lt;Tooltip&gt; and &lt;Legend&gt;</ApiHeading>

The legend defaults to below the chart, centred.
