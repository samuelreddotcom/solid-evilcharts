# Introduction

`@solid-foundation/charts` is a set of copy-pasteable chart components for
SolidJS, built on Apache ECharts 6. It is a port of
[EvilCharts](https://evilcharts.com) — if you write React, use the original.

## A live chart

Preview and source in one place. The Code tab shows the registry source — the
exact bytes `shadcn add` writes into your project, not a hand-copied snippet:

## What ships

| Piece | Where it lives |
| --- | --- |
| Chart components | `src/registry/charts/<name>/` |
| Shared primitives | `src/registry/lib/` |
| Vendored UI | `src/components/ui/` — *not* distributed |

## Installing

```bash
npx shadcn@latest add @solid-foundation/line-chart
```
